# Setara Explorer

Customized [Ping.pub](https://ping.pub) block explorer for the Setara Network.

## Run

```bash
docker compose up -d --build
```

Explorer will be available at `http://localhost:8090`.

## Configuration

Edit `chain.json` to configure RPC/REST/gRPC endpoints for your Setara node.
